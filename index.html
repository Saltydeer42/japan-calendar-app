This app keeps the itinerary in your private GitHub repo. Paste a token once and this device is set up for good.

  1. Open github.com/settings/personal-access-tokens/new
  2. Under Repository access, choose Only select repositories and pick japan-calendar
  3. Under Permissions → Repository permissions, set Contents to Read and write
  4. Set an expiry that outlasts the trip, generate, and copy the token
